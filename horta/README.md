# Horta Escolar 2.0

Sistema de gestão em um arquivo HTML autocontido: dashboard, finanças, plantio, estoque, equipe, backup e exportação Excel. Dados locais ao navegador, sem sincronização entre dispositivos. Valores da demonstração e do modelo de simulação são hipotéticos.

Branch de publicação isolada: preserva a branch `main` e o projeto de barbearia. Esta hospedagem é temporária, até existir um repositório público exclusivo da horta.

## Hospedagem
Render Static Site: build `echo 'ok'`, publish dir `horta`, branch `horta-escolar-v2-publicacao`.

## Aviso
Limpar dados do navegador pode apagar os registros. Exporte backup JSON para segurança.
