CONTROLE DE DISPONIBILIDADE

HORÁRIOS & FOLGAS.

EXPEDIENTE SEMANAL

Os horários salvos são exibidos para os clientes na agenda pública. Use Substituir dia para trocar os turnos anteriores, Adicionar turno para criar um segundo período ou Fechar dia para remover o expediente semanal. Reservas existentes não são canceladas.

Isso libera para os clientes os turnos cadastrados, respeitando folgas e reservas existentes.

O formulário usa domingo = 0, segunda = 1, ... sábado = 6. A agenda do cliente atualiza a disponibilidade a partir desses turnos. Para definir almoço, substitua o dia pelo turno da manhã e depois adicione o turno da tarde.

BLOQUEAR DIA / INTERVALO

Reserve folgas, feriados ou compromissos pessoais. Horários já agendados não são cancelados automaticamente.

PERSONALIZAÇÃO E INTEGRAÇÕES

CONFIGURAÇÕES.

DADOS DA BARBEARIA

Configure preços, expediente e telefone antes de ativar. Desativar impede novas reservas, mas não cancela as existentes.

AGENDA NO IPHONE / ANDROID

Assine esta URL privada no Apple Calendar, Google Agenda ou outro app de calendário com suporte a assinaturas ICS.

Não compartilhe esse link: ele contém nomes dos clientes e informações das reservas. Ao gerar um novo link, o anterior deixa de funcionar. A frequência de atualização depende do app de calendário.

LEMBRETES NO WHATSAPP

Consultando a configuração…

Enquanto o tipo de WhatsApp não estiver definido, use o link privado da solicitação e, se quiser, copie uma mensagem no painel para avisar o cliente manualmente. Copiar a mensagem não realiza o envio.

O tipo de WhatsApp ainda não foi informado. O sistema opera sem integração automática; para enviar mensagens pelo número comercial, será preciso configurar a WhatsApp Cloud API oficial e aprove um template de lembrete com botões CONFIRMAR e CANCELAR. A integração não é ativada apenas ao preencher o telefone acima.

Enquanto as credenciais não estiverem configuradas no servidor, os lembretes não serão enviados. Consulte o README para a configuração.
